# snr-figs 圖片說明

這個 repo 存放 MSNR / 交易課程的截圖(course1、course2、fvg、rick 系列共 11 張 png)。
來源是影片畫面截圖。

## ⚠️ 重要:這些圖是「超寬時間軸」

- 每張都是 **200~300:1 的超寬長條圖**(例如 `105832 × 430` 像素)
- 內容是把整段 K 線時間軸壓成一行呈現

## 為什麼手機看不到

- **iPhone 圖片解碼器無法載入超過數萬像素寬的圖** → 開圖會黑屏/一條白線
- 這不是檔案損壞(檔頭正常、可解碼),是尺寸超過手機限制

## 怎麼看

- ✅ **電腦**:直接開(瀏覽器 / 圖片檢視器都行)
- ❌ **手機**:原生檢視器黑屏 → 不要用手機看這些圖

## 若要手機看(可選方案)

1. 切成小段(每 ~1000px 一段)→ 缺點:檔案變多
2. 轉 PDF → iPhone PDF reader 可看超寬
3. 直接看 vault 裡的文字版 MSNR 筆記(已整理)
